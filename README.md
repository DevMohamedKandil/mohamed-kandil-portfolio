# Mohamed Kandil — Portfolio

Bilingual (Arabic/English) personal portfolio for Mohamed Kandil, Full Stack .NET Developer.

- **Site:** https://devmohamedkandil.github.io/mohamed-kandil-portfolio/
- Arabic (RTL) by default, English (LTR) with one click — preference is remembered.
- Light/dark theme toggle.
- Featured live products: [Afthath ERP](https://afthath.com.sa/) and [Ittihad Al-Mullak](https://ittihad-al-mullak.pages.dev/).
- Downloadable CV (`cv.pdf`).

## Stack

Plain **HTML + CSS + JavaScript**. No build step, no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8080
# or
npx serve .
```
